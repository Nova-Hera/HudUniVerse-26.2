HudUniVerse 1.3.1 - Top Location Text Resource Pack

This pack hides only the WHITE BossBar background/progress textures.
HudUniVerse 1.3.1 uses a white BossBar as a text carrier, so players see
only the territory name at the top of the screen. The BossBar remains
permanently visible and changes text when Towny territory changes.

Minecraft Java Edition 26.2 / resource pack format 88.

Install:
1. Put HudUniVerse-TopText-26.2.zip in the client's resourcepacks folder.
2. Enable it in Minecraft.
3. Keep the HudUniVerse plugin installed on the server.

Important:
- The pack is required for the bar itself to be invisible.
- Other WHITE BossBars will also have their graphics hidden while this pack is active.
- Other BossBar colors remain unchanged.
